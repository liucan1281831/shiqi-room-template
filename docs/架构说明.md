# 架构说明

## 总览

```
[安卓壳 APK / 浏览器]
        │  HTTP + SSE（Bearer token 或 Cookie）
        ▼
[手机 Termux: server.mjs :8660] ──► [bot.mjs] ──► LLM（OpenAI 兼容接口）
        │                              │
        │                              ├─ TTS（语音条 / 唱歌）
        │                              ├─ ASR（听写语音输入）
        │                              └─ 视觉模型（识图）
        ├─► data/msgs/<频道>/<日期>.jsonl   聊天记录（按天分文件）
        ├─► data/uploads/                   图片 / 语音 / 视频
        ├─► data/accounts.json              账号与频道权限
        └─► 云服务器（可选）：防盗备份 / 公网入口 / 视频托管
```

## 关键组件

| 组件 | 职责 |
|---|---|
| `server.mjs` | HTTP + SSE；鉴权（Bearer / `token:` 头 / Cookie）；频道权限；消息落盘；限流；上传；版本与更新 |
| `bot.mjs` | 定时 tick：自然聊天、主动问候、唱歌、每日播报、游戏邀请；调 LLM / TTS / VL |
| `quality.mjs` | 历史去重（近重复检测）、冷却词、每日成长（把当天聊天蒸馏成「变化纸条」注入次日提示词） |
| `singify.mjs` | 歌词 → 音高包络 → TD-PSOLA 变调 → 与原曲伴奏对齐 |
| `memory.mjs` | 每日记忆摘要（digest / long），供跨天延续 |
| `call-ws.mjs` | 手写 RFC6455 WebSocket，语音通话：客户端流式上传 16k PCM，服务端回 TTS |
| `vidload.mjs` | 小剧院：取视频元信息、下载、入库，姐妹自动评论 |
| `apk/` | WebView 壳：前台服务（SSE 通知）、原生录音桥、下载安装、大屋 3D 静态资源本地加载 |

## 数据与权限

- **频道**：`family`（全家）、`lobby`（访客大厅）、`v<id>`（每个访客独立频道）、`dm_*`（私聊）
- **角色**：`family`（家人，可见全部 + 私聊）、`bot`（机器人）、`visitor`（访客，只看到自己的频道）
- **鉴权**：登录换 48 字符 token；后续请求带 `Authorization: Bearer`（或 Cookie）
- 所有 `/api/*` 都鉴权；仅 `/house/*` 等静态 3D 资源公开只读

## 实时推送

客户端订阅 `/api/stream?channel=…`（SSE）。服务端广播三类事件：
`message`（新消息）、`patch`（撤回/编辑/表情回应）、`presence`（在线状态）。
断线自动重连并补拉最近消息。

## 部署拓扑（示例）

1. **单机**：手机跑 `server.mjs`，同一 Wi-Fi 内浏览器访问 —— 最简单
2. **公网**：手机 + frp/内网穿透 → 云服务器 443 反代
3. **云备份**：手机每晚把 `data/` 打包推到云服务器（分片、环形保留）

## 扩展点

- 换模型：只改环境变量里的 baseURL / model / key
- 加频道：`DM_LIST` 里加一条，前端侧栏自动出现
- 加游戏：`server.mjs` 的 `/api/games` + 前端 `#gameOv`
- 换音色：`/api/voice` 里三位角色各自的语速/音高/音量参数
