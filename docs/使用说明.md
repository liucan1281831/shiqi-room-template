# 使用说明

## 1. 环境要求

- Node.js **18+**（手机上：Termux `pkg install nodejs`）
- 可选：大模型 API（OpenAI 兼容：baseURL + key + model 名）
- 可选：安卓壳构建需要 JDK 17 + Android SDK（`apk/build-apk.ps1`）

## 2. 首次运行

```bash
node server.mjs
```

- 首次启动自动创建 `data/`：账号库 `accounts.json`、管理员口令 `admin-pass.txt`
- 管理员账号名默认为 `家长`，口令见 `admin-pass.txt`，**登录后请立刻改**
- 默认监听 `0.0.0.0:8660`

## 3. 接大模型

```bash
export ROOM_LLM_URL=https://your-llm-host/v1/chat/completions
export ROOM_LLM_KEY=sk-xxxx
export ROOM_MODEL=your-model
node server.mjs
```

`bot.mjs` 会用同一套变量；不配也能跑，只是姐妹们不说话。

## 4. 语音与识图（可选）

| 能力 | 变量 | 说明 |
|---|---|---|
| 语音听写 | `ROOM_ASR_URL` | faster-whisper 兼容服务，收 16k 单声道 wav |
| 语音合成 | `ROOM_TTS_URL` + key | 返回 wav 链接 |
| 识图 | `ROOM_VL_URL` | 视觉模型（OpenAI 兼容） |

三者都可放在局域网另一台机器上（如 PC 显卡机），手机只负责聊天与存储。

## 5. 安卓壳

```bash
# Windows
powershell -ExecutionPolicy Bypass -File apk/build-apk.ps1
```

注意：
- `AndroidManifest.xml` 的 `versionCode` 必须**大于**手机上已装版本，否则安装报 `INSTALL_FAILED_VERSION_DOWNGRADE`
- 页面改动后要同步到 `apk/assets/www/index.html` 再打包

## 6. 数据在哪

```
data/msgs/<频道>/<YYYY-MM-DD>.jsonl   聊天记录（一行一条）
data/uploads/                        图片 / 语音 / 视频
data/accounts.json                   账号、角色、频道
data/releases/                       发布包与版本号
```

备份 = 直接打包 `data/`；本模板**不含**任何数据。

## 7. 常见坑

- 改了 `index.html` 必须**重启 server**（页面在启动时缓存进内存）
- 手机 Termux 进程会被系统冻结：需要 `termux-wake-lock` 或前台通知常驻
- 公网访问建议加反代 + HTTPS；裸 IP 访问先确认安全组放行
