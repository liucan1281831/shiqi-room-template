# 家庭小屋 · Family Room（开源模板）

一个**跑在手机上的家庭 AI 聊天小屋**：三姐妹（大姐 / 二姐 / 三姐）由大模型驱动，
老大（家长）随时进去聊。手机 Termux + root 就能当服务器，浏览器或安卓壳当客户端。

> 本仓库只放**脱敏模板与架构文档**，不含任何真实聊天记录、账号、密钥、图片视频。
> 客户端 APK 不在此仓库（APK 由各自部署方自行构建，见 `docs/使用说明.md`）。

## 它长什么样

- **聊天**：文字 / 表情包 / 图片 / 语音条 / 视频，SSE 实时推送、已读回执、引用回复、@ 点名
- **三姐妹各有性格**：人设、口头禅、说话节奏独立可调；有去重与「每日成长」机制，避免复读
- **游戏厅**：记忆翻牌、2048、贪吃蛇、五子棋，姐妹在旁边陪玩解说
- **小剧院**：视频上传、云端托管、边下边播，姐妹自动评论
- **唱歌**：歌词 + TD-PSOLA 变调合成，真唱不是念
- **语音通话**：原生录音 + WebSocket 流式，姐妹用 TTS 回话
- **三端同步**：手机微信 / QQ 机器人与小屋互通
- **运维件**：每日备份上云、检查更新、阈值面板、离线信箱

## 快速开始

```bash
# 手机上（Termux）
pkg install nodejs
mkdir -p ~/familyroom && cd ~/familyroom
# 解压 familyroom-template.zip 到此处
node server.mjs            # 默认监听 :8660
```

浏览器打开 `http://127.0.0.1:8660`，首次运行会自动生成 `data/`（账号库、口令文件）。

## 目录

```
server.mjs        服务端（Node 18+，零第三方依赖）
bot.mjs           姐妹们的聊天 / 唱歌 / 定时播报机器人
index.html        前端单页
quality.mjs       去重与每日成长
singify.mjs       唱歌合成（TD-PSOLA）
memory.mjs        每日记忆摘要
call-ws.mjs       语音通话 WebSocket
vidload.mjs       小剧院视频搬运
status.html       状态页
apk/              安卓壳源码（WebView + 前台通知 + 原生录音）
```

文档见 [`docs/架构说明.md`](docs/架构说明.md)、[`docs/使用说明.md`](docs/使用说明.md)。
